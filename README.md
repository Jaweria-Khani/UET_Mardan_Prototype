# UET Mardan Website Redesign Prototype

Modern responsive redesign of UET Mardan’s legacy portal. Built for Web Engineering course to improve accessibility, readability, and mobile experience for 15,000+ students & faculty.

## 🔗 Live Demo
[View on Vercel](https://uetmardanprototype-jaweria-khans-projects.vercel.app/)

## 🎯 Problem
Original UET website used old CMS with:
- Dense text blocks, poor information hierarchy
- Weak mobile responsiveness
- Low contrast ratio ~3.2:1, failing WCAG standards
- Slow load times on 3G networks

## ✨ Key Features
1. **Responsive UI/UX**: Mobile-first design using Flexbox + CSS Grid. Clean navigation with 7 main sections: Home, About, Departments, Student Life, Facilities, News, Contact
2. **Modern Hero Section**: Full-width banner with overlay + clear CTAs for "Admissions" and "Quality Enhancement Cell" to improve conversion
3. **TypeScript Frontend**: 98% TypeScript for type-safety, maintainability vs legacy PHP
4. **Accessibility Upgrade**: High contrast text + buttons, semantic HTML, keyboard navigation. Target: WCAG 2.2 AA compliance
5. **Performance**: Deployed on Vercel with CDN + automatic CI/CD. Optimized images + clean CSS

## 🛠 Tech Stack
- **Language**: TypeScript 98%, HTML5
- **Styling**: CSS3, Flexbox, CSS Grid, Responsive Design
- **Deployment**: Vercel
- **Tools**: Git, GitHub, VS Code
